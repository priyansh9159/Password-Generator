# SecureKey Password Generator

A responsive password generator built with HTML, CSS, and vanilla JavaScript.

## Run it
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. Choose a length and character options, then click **Generate password**.

Clipboard access works best on localhost or HTTPS. Password generation uses the browser Web Crypto API and does not send passwords to a server.

## Files
- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — password generation, strength estimate, and copy feature
